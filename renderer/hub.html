Apprendre ScratchCode

Un fichier par lutin

Chaque projet est un dossier. Le code de chaque lutin est dans sprites/Nom.sc, celui de la scène dans stage.sc. Le fichier .sb3 est régénéré à chaque exécution.

Raccourcis essentiels

Maj Maj rechercher partout · Maj+F10 lancer · Ctrl+F2 arrêter · Ctrl+E fichiers récents · Alt+Insér nouveau lutin

Syntaxe

Un bloc par ligne, quatre espaces pour l'intérieur d'une boucle, end pour la fermer. Le guide complet est dans SCRATCHCODE.md, dans chaque projet.

Modèles

Le projet est enregistré au format .sb3, compatible avec Scratch, TurboWarp et ScratchCode.
